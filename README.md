# homebrew-fastbg

Homebrew tap for [FastBG](https://github.com/heathdutton/FastBG): video and live web backgrounds in any app.

## Install

```bash
brew tap heathdutton/fastbg
brew install --cask fastbg
```

Apple silicon, macOS 14.4 or later. The cask follows FastBG's latest release within the hour.
